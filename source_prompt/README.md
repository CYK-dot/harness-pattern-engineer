# source_prompt

> **何时读我**：准备撰写、修改或评审任何一份认知工程文档时。

本目录是唯一事实源：平台无关的认知，人机可读。它由三篇构成，按下面的顺序读——**先学怎么说，再学一份东西怎么组织，最后学一整套工程怎么组织。**

## 文件

| 文件 | 回答什么 | 何时读 | 状态 |
|---|---|---|---|
| `00_如何清晰地表述与论证.md` | 话怎么说清、理怎么讲圆：书面语、防上下文污染、论点与论据 | 动笔写任何一段正文之前，或写完自查时 | 已有 |
| `01_如何写一份模式.md` | 一份模式怎么写：四类组成、命名、拆分、评审 | 编写 / 修改 / 评审任何一份模式时 | 已有 |
| `02_如何编写一份认知工程.md` | 一套认知工程怎么组织：源 / 编译 / 产物 | 要新建一套认知工程，或要调整它的目录与分层时 | 已有 |
| `模式模板.md` | 动手写新模式时的填空骨架 | 动手写新模式时 | 已有 |

## 阅读顺序

1. `00` —— 表述与论证。它是地基：无论写哪一篇，都得先会用书面语、会立论点、会补论据。
2. `01` —— 一份模式怎么组织：四类组成、命名、拆分。
3. `02` —— 整套工程怎么组织：源、编译、产物三层。

（`01` 与 `模式模板.md` 是动手时用的；`00`、`02` 是它们背后的方法。）
