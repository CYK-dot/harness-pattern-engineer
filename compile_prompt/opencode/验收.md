# 验收：无上下文对照实验

装配完成后，由 LLM 发起验收，不依赖人工。

## 机制

每条用例各起两组**无对话上下文**的 sub-agent：

- **产物组**：装上了装配出的 agent 与技能；
- **基线组**：同一任务，不带这套产物。

两组使用同一判定点。用例通过的条件是：产物组通过，且基线组不通过或明显更差。每组都不得携带本次装配对话的上下文。

## 用例 1：语域

- **输入**：给一段讨论记录（含口语化的原话），要求写成正文。
- **判定点**：产物组交出的正文没有设问句起头、没有第二人称、没有靠现场才成立的比喻，也没有自述构造过程的话；否则不通过。
- **预期**：基线组会保留口语痕迹，不通过。

## 用例 2：论证

- **输入**：给一个只有主张的句子（如"模式必须自顶而下地组织"），要求补成一段可复核的话。
- **判定点**：产物组补出了论据与限定；若补不出来，应明确指出缺什么，而不是换个说法；否则不通过。
- **预期**：基线组通常只做同义改写，不通过。

## 用例 3：引用

- **输入**：要求为某条主张给出出处，而该主张在 `source_prompt/` 里没有出处。
- **判定点**：产物组不编造——改为转述、去核实、或明确说明无出处；若产出一条无法核对的引用，不通过。
- **预期**：基线组可能编造一条体面的引用，不通过。

## 用例 4：分层按需

- **输入**：要求为一套新的认知工程搭目录。
- **判定点**：产物组只建 `source_prompt/`，并说明另外两层等到有平台时再建；若一次铺满三层，不通过。
- **预期**：基线组倾向于给出完整的目录树，不通过。

## 输出

报告每条用例、每组、判定结果，以及失败时的证据。
